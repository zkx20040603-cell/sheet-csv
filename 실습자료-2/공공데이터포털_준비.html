6주차 수업(10/7) 전까지 공공데이터포털에서 Open API 인증키를 받아 둡니다. 승인과 키 반영에 시간이 걸릴 수 있어 미리 신청합니다.

1. 가입과 로그인

공공데이터포털에 회원가입하고 로그인합니다.

2. API 찾기

  1. 검색창에 API 이름을 입력하고, 결과에서 오픈 API 탭을 고릅니다.
  2. 상세 화면에서 제공기관, 요청 변수, 응답 형식(JSON 지원 여부), 일일 트래픽을 확인합니다.
  3. 이용허락범위(출처 표시 조건)도 함께 봅니다. 6주차에 README 출처 표기에 씁니다.

3. 활용신청

  1. 상세 화면의 활용신청을 누릅니다.
  2. 활용 목적에 ‘대학 수업 실습(웹서비스 개발)’처럼 적고 신청합니다.
  3. 대부분의 API는 개발계정이 자동 승인됩니다. 심의가 필요한 API는 승인까지 며칠 걸릴 수 있습니다.

4. 인증키 확인

마이페이지의 Open API 활용신청 현황에서 신청한 API를 열면 일반 인증키가 보입니다. Encoding과 Decoding 두 가지가 있으며, 어느 것을 쓰는지는 6주차에 배웁니다.

승인 직후 호출하면 인증키 오류가 날 수 있습니다. 보통 한두 시간 뒤에 정상 호출됩니다.

5. 인증키 다루기

인증키는 비밀번호처럼 다룹니다. 6주차에 GitHub Secrets에 등록하고, 코드·README·단톡방·스크린샷에는 적지 않습니다.

  • 6주차 수업 예제: 모두 한국천문연구원_특일 정보를 신청합니다.
  • 개인 프로젝트나 팀별로 해 보기에 쓸 API가 있으면 자기 계정으로 하나 더 신청합니다.

6. 예시 API

공공데이터포털에서 바로 쓸 수 있는 예시입니다. 모두 개발계정이 자동 승인됩니다(2026-09-26 확인). 이용 조건과 하루 호출 수는 API마다 다르니 상세 화면에서 확인합니다.
