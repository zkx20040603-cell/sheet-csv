시트와 게시

증상 원인 해결
‘웹에 게시’ 메뉴가 없음 학교 계정 관리자가 게시를 막음 개인 구글 계정으로 시트를 만들고, 함께 고칠 사람을 편집자로 초대
게시 주소를 열면 웹페이지가 보임 형식을 ‘웹페이지’로 게시 웹에 게시 창에서 형식을 ‘쉼표로 구분된 값(.csv)’으로 바꿔 다시 복사
로그: CSV 대신 웹페이지가 왔습니다 편집 주소(…/edit)를 등록했거나 게시하지 않음 웹에 게시에서 나온 …/pub?…output=csv 주소를 변수에 등록
로그: 404 응답 주소 일부가 잘렸거나 게시를 중지함 주소 전체를 다시 복사하고 게시 상태 확인
시트를 고쳤는데 웹이 그대로 워크플로를 다시 실행하지 않았거나, 게시 내용 반영이 늦음 Run workflow로 다시 실행. 그래도 같으면 몇 분 뒤 한 번 더 실행
다른 탭 내용이 나옴 게시할 시트를 다른 탭으로 선택 웹에 게시 창에서 콘텐츠 탭을 골라 다시 게시하고 새 주소 등록

데이터 약속

로그 원인 해결
필수 열이 없습니다: 내용 / 현재 열: … 1행 열 이름 오타·띄어쓰기 현재 열 목록을 보고 제목, 내용, 공개를 정확히 적기
공개 열이 Y인 행이 없습니다 공개 열이 비었거나 다른 값 웹에 보일 행에 Y 적기
n행의 제목이(가) 비어 있습니다 공개=Y인데 제목·내용이 빈 행 해당 행을 채우거나 공개를 N으로
n행의 링크는 http:// 또는 https://로 시작해야 합니다 www.로 시작하거나 다른 글자 주소 앞에 https://를 붙이거나 칸 비우기
한글이 깨져 보임 CSV를 다른 인코딩으로 저장 구글 시트에서 게시한 CSV를 쓰거나, 로컬 CSV를 UTF-8로 저장

n행은 시트의 행 번호입니다. 1행이 열 이름이므로 첫 데이터 행이 2행입니다.

Actions와 Pages

증상 원인 해결
바닥글에 ‘로컬 파일 sample.csv’ 저장소 변수가 없거나 이름이 다름 Variables 탭(Secrets 아님)에 SHEET_CSV_URL 정확히 등록 후 다시 실행
워크플로가 두 개 실행되고 하나가 실패 기존 저장소에 4주차 daily_quote.yml이 남아 있음 Pages에 배포하는 워크플로를 하나만 남기기
deploy 단계 실패 Pages Source가 GitHub Actions가 아님 Settings → Pages → Source를 GitHub Actions로 설정 후 다시 실행
워크플로 목록에 안 보임 파일 위치가 .github/workflows/가 아님 저장소 최상위의 .github/workflows/sheet_site.yml 경로 확인
로그: 시트 주소에 연결하지 못했습니다 일시적인 네트워크 문제 잠시 뒤 Re-run jobs

볼 때 읽기(선택) 예제

증상 원인 해결
파일을 더블클릭하면 ‘불러오지 못했습니다’ 브라우저가 로컬 파일 읽기를 막음 예제 폴더에서 python3 -m http.server 8000 실행 후 http://localhost:8000/extras/sheet-live.html
새 내용이 안 보임 게시 내용 반영이 늦음 몇 분 뒤 새로고침
